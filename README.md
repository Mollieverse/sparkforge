# SparkForge — AI Marketing Co-Founder for Solana

Ship killer marketing in minutes. Built for early-stage Solana builders.

Live App: https://sparkforge-s2zu.vercel.app/


What is SparkForge?

SparkForge is an AI-powered marketing copilot built exclusively for Solana builders. Instead of spending hours writing tweets, Pump.fun descriptions, and launch announcements  SparkForge generates hyper-personalized marketing content in seconds.

Think of it like ChatGPT, but each project is its own intelligent workspace with full memory of your brand, history, and generated assets.


 Features

- Project Memory:Each project stores its own brand context, voice, and history
- AI Copilot: Powered by Claude Sonnet (Anthropic)
- Asset Library: Every generated asset saved per project
- Multi-Project: Switch between projects, history never lost
- Solana-Native: Built for CT culture, Pump.fun, Raydium, Jupiter
